# 1. WEB — 회원 포털 (감리원용)

## 1-1. 로그인 (본인인증)

1. 포털 접속 후 우측 상단 **본인인증** 버튼 클릭
2. 성명 · 생년월일 · 휴대폰 번호 입력 → **PASS 본인인증** 진행
3. 인증이 완료되면 자동으로 로그인됩니다 (별도 비밀번호 없음)

> 💡 **자동 매칭**: 본인인증 결과의 **이름 + 생년월일**이 기존 등록된 교육생과 일치하면 자동으로 연결됩니다. 같은 이름·생일의 교육생이 2명 이상이면 자동 매칭하지 않고 심사로 넘어갑니다.

## 1-2. 심사 대기 상태일 때

본인인증은 됐는데 기존 교육생 데이터와 매칭되지 않으면:

- 화면에 **"교육생 심사가 진행 중이에요"** 안내가 표시됩니다
- 협회에서 수동으로 매칭 심사를 완료하면(영업일 1~2일) **다시 로그인**할 때 정상 이용 가능합니다
- 심사 중에는 이력 조회·확인서 발급을 할 수 없습니다

## 1-3. 교육 이력 조회

- 로그인 후 **교육 이력** 페이지에서 본인의 교육 이력이 표시됩니다
- 협회 교육 + 외부 교육 수료 이력이 모두 표시됩니다
- 각 이력의 과정명 · 기관 · 교육기간 · 이수시간 · 수료 상태(진행중/수료)를 확인할 수 있습니다

## 1-4. 확인서(교육확인서) 발급 — 결제 포함

1. 교육 이력 목록에서 발급할 이력 선택 → **확인서 발급** 클릭
2. 발급 유형 확인 (최초 발급 / 재발급)
3. **결제** — 회원등급별 발급 단가로 결제됩니다
   | 회원등급 | 발급 단가 |
   |---|---|
   | 일반 | 3,000원 |
   | 평생 | 1,800원 |
   | 연간 | 1,800원 |
4. 결제 완료 → **발급 완료 페이지**에서 확인서 미리보기 확인
5. **PDF 다운로드** 클릭 → PDF 저장 (브라우저 인쇄로도 저장 가능)

> ⚠️ 확인서에는 성명 · 과정명 · 기관 · 교육기간 · 이수시간 · **감리원 등급 · 감리원증 발급번호**가 인쇄됩니다. 정보가 비어 있으면 협회에 정정 요청 후 재발급 받으세요.

## 1-5. 재발급

- 발급 후 **7일 이내 재발급은 무료**
- 7일 경과 후 재발급은 재결제가 필요합니다
- 발급 정보에 오류가 있는 경우: 협회에서 이력을 정정한 뒤 재발급 받으세요

## 1-6. 결제 내역

- **결제 내역** 페이지에서 발급 결제 이력을 확인할 수 있습니다
- 상태 표시: `결제완료` / `환불` (환불된 건은 회색으로 표시)
- 환불은 협회에서 처리하며, 처리되면 이 화면에 자동 반영됩니다

# 2. ADMIN — 관리자 (협회 운영 담당자용)

> 접속: 관리자 URL → 이메일 + 비밀번호 로그인
> 좌측 사이드바 기준으로 각 메뉴를 설명합니다.

## 2-1. 대시보드

| 영역 | 내용 |
|---|---|
| KPI 카드 | 심사 대기 · 교육생 수 · 발급된 확인서 · 결제 완료 — 클릭 시 해당 페이지로 이동 |
| **이번 주 교육 일정 (7일 내)** | 앞으로 7일 안에 열리는 교육 일정 목록 → 우측 상단 링크로 교육 일정 관리 이동 |
| **최근 7일 결제** | 최근 일주일 결제 내역 (주문번호 · 금액 · 상태) → 결제 내역 이동 |

## 2-2. 교육생 관리

교육생 마스터를 관리하는 화면입니다.

**검색**
- 검색창 하나로 **성명 · 교육생번호 · 감리원증번호**를 동시에 검색합니다

**중복확인 버튼**
- 이름 개명 등으로 **감리원증번호가 중복된 교육생 목록**을 별도로 조회합니다
- 증번호별로 그룹 표시 → 행의 이름을 클릭하면 수정 모달이 열리고, **삭제** 버튼으로 바로 정리할 수도 있습니다

**교육생 등록 (신규)**
1. 우측 상단 **등록** → 모달에서 입력
2. 항목: 성명(필수) · **감리원증번호** · **감리원 등급**(감리원/수석감리원) · 생년월일 · 전화번호 · 이메일 · 회원등급 · 메모
3. 교육생번호는 자동 부여됩니다 (`TR-날짜-일련번호`)

**교육생 수정**
- 목록 행 **수정** → 같은 모달에서 수정 (감리원증번호·감리원 등급 포함)
- 회원등급 변경은 별도 **등급 변경** 대화상자에서 진행 (변경 이력이 자동 기록됩니다)

**테이블 컬럼**: 교육생번호 · 성명 · 생년월일 · 감리원 등급 · 감리원증번호 · 전화 · 이메일 · 회원등급 · 상태

## 2-3. 교육 일정 관리 — 핵심 메뉴

**교육을 "개설"하고 수강 교육생을 연결하는 흐름의 시작점입니다.**

### 일정 등록
1. 우측 상단 **일정 등록**
2. **과정** 검색 · 선택 (과정명 · 기관명으로 검색)
3. 시작일 · 종료일 · 총 시수 · **인정 시수** · 메모 입력
4. **운영중** 체크 (해제하면 '종료' 상태로 표시)
5. **등록 후 교육생 연결** 클릭

### 교육생 연결 → 교육 이력 자동 생성
1. 등록 직후 **교육생 연결** 화면이 열립니다 (목록에서도 행별 **교육생 연결** 버튼으로 진입 가능)
2. 상단: 이 일정에 **이미 연결된 교육생** 목록 (이수시수·기간 표시)
3. **교육생 추가**: 입력창 클릭 → 드롭다운에서 성명 검색 (입력하는 대로 필터링, 스크롤하면 계속 불러옴) → 체크로 다중 선택
   - 선택된 교육생은 칩으로 표시 (×로 개별 해제)
   - 이미 연결된 교육생은 흐리게 표시되고 중복 연결되지 않습니다
4. 이수 시수(기본값: 일정 인정 시수) · 메모 확인 → **N명 연결** 클릭
5. 선택한 교육생 수만큼 **교육 이력이 자동 생성**됩니다

### 이력 상태 자동 판정
| 일정 상태 | 생성되는 이력 |
|---|---|
| 종료일이 지남 | **수료** — 이수시수 = 일정 인정시수 자동 입력 |
| 종료일이 안 지남 / 기간 미입력 | **진행중** — 이수시수 0. 교육 종료 후 이력 수정에서 수료로 변경 + 이수시수 입력 |

### 목록 필터
- **검색**: 과정명 · 기관명
- **기간**: 시작일 ~ 종료일 선택 (to에서 from 이전 날짜는 선택 불가)
- **상태**: 운영중 / 종료
- 행별: 수정 · 교육생 연결 · 삭제 (삭제해도 연결된 이력은 남아 있고 연결만 끊깁니다)

## 2-4. 교육 이력 관리

모든 교육 이력(사내 교육 + 이관 데이터)을 관리합니다. **외부 교육은 이 화면에 나오지 않습니다** — 외부 수료 관리 메뉴를 사용하세요.

**검색 / 필터**
- 검색: 과정명 · 기관명 · 교육생 성명
- **기간**: 교육 기간이 기간 내에 겹치는 이력 검색
- 구분(사내/이관) · 수료상태 필터

**방법 ① 일정으로 등록 (권장)**
1. 우측 상단 **일정으로 등록**
2. 교육 일정 검색 · 선택 → 과정명 · 기관 · 기간 · 시수가 **자동으로 채워짐**
3. 교육생 다중 선택 → 저장 → 일괄 생성

**방법 ② 직접 등록 (외부교육·단건)**
1. **이력 등록** → 교육생 검색 · 선택 (없으면 그 자리에서 신규 교육생 등록 가능)
2. 과정 검색 · 선택 → 과정명 · 기관 · 시수 자동 채움. 목록에 없는 교육은 선택 해제 후 직접 입력
3. 시작/종료일 · 이수시간 · 수료상태 · 메모 입력
4. 확인서 표기용 감리원 등급·증번호는 교육생 정보에서 자동 반영됩니다

**수정**
- 행 **수정** → 이수시간 · 수료상태 · 날짜 · 메모 등 수정 (진행중인 교육 수료 처리도 여기서)

**삭제**
- 소프트 삭제 — 데이터는 남고 목록에서만 숨겨집니다

## 2-5. 외부 수료 관리

감리원이 **개인적으로 수료한 외부 교육** 이력만 모아 보는 화면입니다 (교육이력관리의 외부 전용 뷰).
- 등록 · 수정 · 삭제는 교육 이력 관리와 동일하게 동작합니다
- 검색 · 기간 필터 제공

## 2-6. 기관 · 과정 관리

**탭 2개(기관 / 과정)로 구성되고, 모두 페이지네이션 · 검색 · 필터를 제공합니다.**

### 기관 탭
- 검색: 기관명 · 기관코드
- 상태 필터: 사용중 / 비활성
- 등록 · 수정 · 삭제 (삭제는 활성 과정이 남아 있으면 차단됩니다)

### 과정 탭
- 검색: 과정명 · 과정코드 · **회차명 · 기관명** 동시 검색
- 필터: 상태 · **구분(계속교육/외부교육)** · 분류
- 컬럼: 구분 · 과정명 · 회차명 · 소속기관 · 과정코드 · 분류 · 시수 · 상태

**과정 등록 · 수정**
1. 소속 기관: 검색해서 선택 — **없으면 `+ '검색어' 새 기관으로 추가` 클릭으로 즉시 생성**
2. 회차명: 회차명 마스터에서 선택 — **없으면 즉시 생성 가능** (회차명 관리에 자동 등록)
3. 과정명 · 과정코드(기존 코드 검색 또는 직접 입력) · 총 시수 · 분류(기존 분류 검색 또는 신규 입력)
4. **외부 교육과정** 체크 — 감리원이 개인적으로 수료한 외부 교육이면 체크 (구분이 '외부'로 표시됨)

## 2-7. 회차명 관리

과정 등록에서 선택하는 **회차명 마스터**(예: "2019년 1차", "온라인 2차")를 관리합니다.
- 등록 · 수정 · 삭제, 검색 · 상태(사용중/비활성) 필터
- 삭제 시 참조 중인 과정의 회차명은 비워집니다 (과정은 유지)

## 2-8. 회원등급

확인서 발급 **결제 단가**를 정하는 등급입니다.

| 등급 | 발급 단가 |
|---|---|
| 일반 | 3,000원 |
| 평생 | 1,800원 |
| 연간 | 1,800원 |

- 가격은 목록에서 **수정** 가능합니다
- 교육생이 배정된 등급은 삭제(비활성)할 수 없습니다
- ※ 회원등급 ≠ 감리원 등급. 감리원 등급(감리원/수석감리원)은 교육생 관리에서 관리하고 확인서에 표기됩니다

## 2-9. 확인서 발급 내역

발급된 확인서 전체를 관리합니다.

**컬럼**: 증명서번호 · 성명 · 과정 · 기관 · 시수 · 교육기간 · 발급일시 · 상태 · **다운로드** (WEB에서 PDF를 저장한 횟수·최초 일시) · 액션

**검색 / 필터**: 확인서 번호 · 성명 · 과정명 검색 / 상태(발급됨 · 환불 · 대체) / **기간(발급일 기준)**

**환불 (발급 건)**
1. 발급됨 상태의 행 **환불** 클릭
2. 환불 사유 입력(필수) → **폐기 후 환불** 실행
3. 처리 내용:
   - 확인서 **자동 폐기** → 진위확인 조회 시 무효로 표시
   - PortOne 결제 **자동 취소** → 주문 상태 `환불`
   - WEB 회원의 결제 내역에 **"환불"**로 표시
4. 환불 내역은 **결제 내역** 페이지에서도 확인됩니다 (상태: 환불)

> ⚠️ 환불하면 해당 확인서는 무효가 됩니다. 정정 후 재발급이 필요하면 이력 수정 → 회원이 재발급(기간에 따라 무료/유료) 진행.

## 2-10. 결제 내역

확인서 발급 결제 주문 전체를 관리합니다.

**컬럼**: 주문번호 · **결제자**(회원명) · 금액 · 상태 · 결제일시 · 주문일시 · 액션

**검색 / 필터**: 주문번호 · 교육생 성명 검색 / 상태 전체(결제완료 · 환불 · 준비 · 실패 …) / **기간(주문일 기준)**

**환불 처리**
1. 상태가 `결제완료`인 행 **환불** 클릭
2. 사유 입력 → 실행 시:
   - 이 결제로 발급된 확인서 **전부 자동 폐기**
   - PortOne 결제 취소 → 주문 `환불` 상태 변경
   - WEB 회원 결제 내역에 "환불" 표시
3. 준비(결제 미완료) · 실패 건은 환불 대상이 아닙니다

## 2-11. 본인인증 심사

WEB에서 본인인증했지만 **기존 교육생과 매칭되지 않은 회원**이 대기합니다.

**상태(대기 중인 심사 건)**
1. 목록에서 인증 정보(성명 · 생년월일 · 연락처) 확인
2. 두 가지 처리:
   - **기존 교육생 연결**: 검색해서 해당 교육생 선택 → 승인 (이름 개명 등으로 매칭 실패한 경우)
   - **신규 교육생 생성**: 정보 입력 → 승인 (신규 회원인 경우, 확정 등급 필수)
3. 반려도 가능합니다

> 승인되면 회원이 다음 로그인할 때 정상 이용 가능합니다. 자동 매칭(이름+생년월일 일치)은 시스템이 먼저 시도하고, 실패한 건만 여기에 쌓입니다.

## 2-12. 관리자 계정 · 감사 로그

- **관리자 계정**: 관리자 추가 · 이름/권한 수정 · 비밀번호 초기화 · 사용 중지
- **감사 로그**: 관리자의 모든 주요 행동(등록 · 수정 · 삭제 · 승인 · 환불 등)이 기록됩니다. 한국어 라벨로 표시되며 검색 가능합니다

# 3. 자주 묻는 질문 (FAQ)

**Q. 교육 이력의 "진행중"을 수료로 바꾸려면?**
교육 이력 관리 → 해당 행 수정 → 수료상태를 `수료`로 변경 + 이수시간 입력 → 저장.

**Q. 외부 교육 이력은 어디서 관리하나?**
외부 수료 관리 메뉴. 교육 이력 관리 화면에는 외부 이력이 나오지 않습니다.

**Q. 새로운 외부 교육기관 · 과정을 등록하려면?**
기관 · 과정 관리 → 과정 등록 → 소속 기관 검색 후 없으면 '새 기관으로 추가' → **외부 교육과정 체크**.

**Q. 감리원증번호가 중복된 데이터가 보여요.**
교육생 관리 → **중복확인** 버튼 → 그룹으로 표시되는 목록에서 이름 클릭해 수정하거나 삭제로 정리.

**Q. 환불하면 확인서는?**
자동 폐기됩니다 (진위확인 무효). 정정 후에는 회원이 재발급 받아야 합니다 (7일 내 무료).

**Q. 회원이 "심사 대기 중" 화면만 본다고 하는데?**
본인인증은 됐지만 교육생 매칭 심사가 완료되지 않은 상태입니다. 본인인증 심사 메뉴에서 매칭 · 승인해 주면 다음 로그인부터 정상 이용됩니다.

**Q. 확인서에 감리원 등급 · 증번호가 비어 있어요.**
교육생 관리에서 해당 교육생의 감리원 등급 · 감리원증번호를 채운 뒤, 이력 수정으로 다시 저장하면 반영됩니다 (이후 발급분부터).
