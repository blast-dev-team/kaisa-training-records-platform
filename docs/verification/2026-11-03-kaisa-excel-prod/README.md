## 3. 검증 방법 (재검증자용 3-pass)

```
pass 1  compare.py      — 엑셀 canonical ↔ DB 전수 키 매칭 (8개 영역 S1~S7)
pass 2  analyze2~3.py   — 불일치·누락 건의 원인 재분류 (dual-cert 통합 / TR행 / 신구 파일 차이 /
                          의도 제외 / fallback 경로 / soft-delete)
pass 3  analyze4.py + 최종 재판정 — 남은 건에 대해 soft-delete 교차, 통합 보존 형제 레코드
                          (같은 사람 + 과정명 포함 매칭), 시그니처(이름+과정+기간+시간) 세트 비교
```

핵심 보정: 날짜 비교 시 빈값(None/빈문자열)은 동일 취급, `course_sessions` 중복 `schedule_no`는
import 와 동일한 first-wins, 수강신청 `인정시간` 컬럼이 DB hours 의 원천.

재실행 순서는 §8 참고.
