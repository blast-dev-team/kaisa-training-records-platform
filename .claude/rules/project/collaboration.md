# 협업 워크플로우

이 프로젝트는 팀 단위로 작업하므로 파일 수정 전 최신화가 필수다.

## 작업 시작 전 체크리스트

파일 수정 작업을 시작하기 전, 반드시 아래를 먼저 실행한다.

```bash
git pull
```

그 다음 수정 대상 파일을 Read로 읽은 뒤 작업을 진행한다.

## 왜 중요한가

- 다른 팀원이 같은 파일을 수정했을 수 있다
- pull 없이 Edit하면 원격 변경사항을 날릴 수 있다
- 충돌은 나중에 해결하는 것보다 사전에 방지하는 게 낫다

## 예외

- 신규 파일 생성: pull 불필요 (기존 파일 건드리지 않음)
- Read 전용 조회 작업: pull 불필요
- 이미 같은 세션 내에서 pull을 완료한 경우: 재실행 불필요
